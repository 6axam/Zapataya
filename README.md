# Comma Sound

Приложение воспроизводит звук при вводе запятой. В системном трее находятся переключатель, настройки громкости и проверка звука. Нажатия не записываются и не отправляются в сеть.

## Загрузка

На странице Releases выберите архив для Windows x64, macOS (Apple Silicon или Intel) или Linux x64. Для Debian/Ubuntu доступен `.deb`, для Fedora/openSUSE — `.rpm`; архив Linux подходит для ручной установки в других дистрибутивах. Сборки не подписаны: macOS и Windows могут показать предупреждение о неизвестном разработчике.

## Поддержка и ограничения

- Windows: глобальный мониторинг клавиатуры в пользовательской сессии. Приложения с повышенными правами могут быть недоступны приложению без повышения прав.
- macOS: разрешите Comma Sound в «Конфиденциальность и безопасность → Мониторинг ввода» и, если потребуется, «Универсальный доступ». После изменения прав перезапустите приложение.
- Linux X11: необходимы рабочий X-сервер и системный трей. В некоторых окружениях нужен индикатор приложений.
- Linux Wayland: изоляция Wayland не предоставляет универсальный доступ к вводу всех приложений. Обычная версия сообщит об этом и не будет работать глобально. Для Hyprland/Omarchy есть отдельная интеграция ниже; другие Wayland-композиторы пока не поддерживаются.
- Ввод через экранную клавиатуру, IME, вставку текста, удалённый рабочий стол и специализированные приложения зависит от системы и может не распознаваться. Комбинации с Ctrl, Alt или Super не запускают звук.

## Omarchy + Hyprland

Интеграция использует собственный виджет Omarchy и не требует запуска приложения из трея. Она рассчитана на раскладки US, RU и UA, где первая раскладка — US. Файлы проекта должны оставаться на месте при запуске установщика:

```sh
./hyprland/install.sh
```

Добавьте в `~/.config/hypr/bindings.lua` (заменив `/home/USER` на свой путь):

```lua
hl.bind("comma", hl.dsp.exec_cmd("/home/USER/.local/share/comma-sound/control.py play 59 0"), { non_consuming = true, repeating = true })
hl.bind("SHIFT + slash", hl.dsp.exec_cmd("/home/USER/.local/share/comma-sound/control.py play 61 1"), { non_consuming = true, repeating = true })
```

Добавьте виджет `maks.comma-sound` в панель через настройки Omarchy или `omarchy bar put maks.comma-sound --section right`. Затем выполните `hyprctl reload` и `hyprctl configerrors`. В виджете клик включает звук, колесо регулирует громкость. Нужны `python3`, `libxkbcommon`, `paplay` и `hyprctl`. Если эта интеграция уже была установлена, не дублируйте привязки.

## Запуск из исходников

```sh
python3 -m venv .venv
. .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m comma_sound.main
```

## Авторские права на звук

Звуковой файл предоставлен владельцем репозитория; возможность распространять его вместе с приложением должна определяться его правообладателем. Код и звук могут иметь разные условия использования.

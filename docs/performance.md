# Локальный замер обработчика Hyprland

3 ноября 2026 года, существующая машина пользователя: Linux x86-64, Omarchy/Hyprland, русская раскладка. 25 измерений после одного прогрева, медиана; старый код — Python-обработчик из версии 0.1.4, новый — `comma-control` из Rust release. Состояние сохранено в отдельном тестовом каталоге, поэтому пользовательские настройки не менялись. `hyprctl` и обработка раскладки настоящие, `paplay` заменён на `true`: фактическое воспроизведение и задержка аудиоустройства не измерялись.

Время включает создание процесса и, в активном сценарии, запуск `hyprctl` и проверку раскладки. RSS измерен через `wait4` и в активном сценарии может включать пиковое потребление дочернего `hyprctl`; это не RAM всего рабочего стола и не оценка постоянного приложения в трее. Значения зависят от нагрузки и системы.
